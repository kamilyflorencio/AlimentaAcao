# AlimentaAção 🍽️
> Do descarte ao destino.

---

## Sobre o Projeto
O **AlimentaAção** é um projeto acadêmico desenvolvido com o objetivo de contribuir para a redução do desperdício de alimentos, conectando pessoas, restaurantes e organizações sociais.

A plataforma permite visualizar ONGs parceiras, conhecer suas iniciativas, encontrar doações disponíveis e escolher diferentes formas de contribuir.

---

## Objetivo
Facilitar o direcionamento de alimentos que seriam descartados para pessoas e organizações que precisam deles, fortalecendo uma rede de solidariedade e combate ao desperdício.

---

## Funcionalidades
- Visualização das ONGs parceiras e informações sobre as organizações;
- Opções de doação (alimentos ou recursos em dinheiro);
- Visualização do impacto das contribuições;
- Busca de doações próximas, com informações de distância e localização.

---

## Responsividade
O foco deste projeto foi o desenvolvimento da versão web responsiva do aplicativo. O layout foi adaptado para telas maiores (desktops e notebooks), garantindo melhor aproveitamento do espaço, navegação fluida e organização clara dos cards e informações.

---

## Design e Paleta de Cores
A proposta visual busca transmitir acolhimento, solidariedade e nutrição, utilizando elementos gráficos e fotografias. 

Todo o projeto foi **desenvolvido de forma 100% autoral (sem o uso de inteligência artificial na criação do design)** utilizando o **Figma** como ferramenta principal e buscando referências visuais e inspirações na comunidade do **Pinterest**. 

A paleta de cores do projeto utiliza os seguintes tons principais:
- Laranja
- Vermelho / Vinho
- Verde Oliva
- Creme
